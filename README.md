# node-smith

**말 한마디로 ComfyUI 캔버스에 워크플로우를 그리는 AI 코파일럿.**

Claude 같은 에이전트에게 "z-image turbo로 트렌치코트 입은 여성 이미지 만들어줘"라고 말하면,
node-smith가 ComfyUI 캔버스에 **노드를 직접 생성·연결하고 실행해 결과까지 보여줍니다.**

> 단순히 이미 있는 노드의 값을 바꾸는 도구가 아니라, **워크플로우를 처음부터 조립**하는 게 핵심입니다.

## 이게 뭔가요

ComfyUI는 노드를 마우스로 하나하나 놓고 선으로 잇는 노드 에디터입니다. 익숙하지 않으면
어떤 노드를 어떤 순서로 이어야 하는지 아는 것부터가 벽이죠.

node-smith는 그 사이에 **에이전트(Claude)**를 끼웁니다. 사람은 말로 의도만 전하고,
에이전트가 모델별 권장 구조를 판단해 캔버스에 실제로 조립합니다. 만들어지는 과정이
화면에 그대로 보이기 때문에, 결과물뿐 아니라 **"어떻게 만들어지는지"를 배우는 데도** 좋습니다.

**할 수 있는 것**
- 대화로 노드 생성·연결·삭제·이동·크기조절 (한 번의 명령으로 워크플로우 통째 조립)
- 캔버스 상태 읽기 (요약/상세)
- 워크플로우 실행 + 결과 이미지를 대화창에 바로 표시

## 어떻게 동작하나 — 우편함(mailbox) 구조

파이썬(에이전트 쪽)과 브라우저(캔버스 쪽)는 직접 대화하지 않습니다. 대신 **ComfyUI 서버를
우편함처럼** 씁니다.

```
 [명령관]                    [우편함]                     [집배원 + 화가]
 파이썬 MCP 서버  ──명령 넣기──▶  ComfyUI 서버  ◀──0.2초마다 확인──  브라우저 JS
 (Claude가 호출)               (HTTP 라우트)                   → 캔버스에 그림
```

1. **① 우편함** — [`__init__.py`](__init__.py): ComfyUI에 HTTP 라우트를 추가해 명령을 잠시 보관.
2. **② 집배원 + 화가** — [`js/node-smith.js`](js/node-smith.js): 브라우저가 0.2초마다 우편함을 확인해
   명령을 꺼내 표준 LiteGraph API로 캔버스에 그리고, 캔버스 상태를 다시 우편함에 올림.
3. **③ 명령관** — [`mcp_server.py`](mcp_server.py): Claude가 부르는 MCP 도구. 프레임워크 없이
   손으로 짠 JSON-RPC 서버.

이 구조 덕분에 **ComfyUI·에이전트가 한 PC에 있든(로컬), 다른 PC에 있든(원격)** 똑같은 코드로 돕니다.
`COMFYUI_URL` 값만 바꾸면 됩니다.

## 손과 머리를 나눈 설계

node-smith의 **코드는 "손"** 입니다 — 노드를 생성·연결·배치할 뿐, *어떤* 노드를 *어떻게* 이어야
하는지는 모릅니다. 그 판단 재료(**"머리"**)는 [`knowledge/`](knowledge/) 폴더에 **데이터로** 둡니다.

```
knowledge/
└─ <모델>.md      ← 권장 노드 구조·샘플러 값·함정·프롬프트 패턴
```

**왜 코드가 아니라 데이터냐면** — 모델별 권장 구조는 모델이 업데이트되면 계속 바뀝니다.
이걸 코드에 박아두면 모델 하나 늘 때마다 코드를 고쳐야 하죠. 지식을 데이터로 분리해두면
**코드는 그대로 두고 이 폴더만 갱신**하면 됩니다. 현재 Qwen·Z-Image·Flux·WAN·LTX-V 등
7종의 권장 구조가 들어 있습니다. (검증된 워크플로우 JSON을 함께 두고 싶으면 md 옆에 나란히
두면 되고, 이 저장소에는 지식 md만 담았습니다.)

## 설치

1. 이 폴더를 ComfyUI의 커스텀 노드 위치에 둡니다.
   ```
   ComfyUI/custom_nodes/node-smith/
   ```
2. ComfyUI를 재시작하고 브라우저 탭을 새로고침합니다 (JS가 로드되도록).
3. 에이전트(예: Claude Code)의 MCP 설정에 명령관을 등록합니다.
   ```json
   {
     "node-smith": {
       "command": "python3",
       "args": ["/경로/node-smith/mcp_server.py"],
       "type": "stdio",
       "env": { "COMFYUI_URL": "http://127.0.0.1:8188" }
     }
   }
   ```
   ComfyUI가 다른 PC에 있으면 `COMFYUI_URL`을 그 주소로 바꿉니다.

## MCP 도구

| 도구 | 하는 일 |
|------|---------|
| `edit_graph` | **간판 기능.** 노드 생성·연결·삭제·이동·크기조절·값설정을 한 번에 (ref 체이닝으로 조립+연결 동시) |
| `get_workflow` | 캔버스 전체를 원본 그대로 반환 |
| `summarize_workflow` | 캔버스 요약 (노드·연결 목록, 가벼움) |
| `get_node_info` | 특정 노드 상세 (입출력·연결·값) |
| `get_node_types` | 사용 가능한 노드 사전 |
| `run` | 워크플로우 실행(큐) / 중단 |
| `view_image` | 최신 출력 이미지를 대화창에 표시 |
| `center_on_node` | 특정 노드로 화면 이동 |

> 도구 정의는 매 세션 읽히므로, 이름·설명·응답을 **짧게** 유지하는 걸 1급 원칙으로 삼았습니다.
> 응답은 거대 JSON 대신 `id,type,x,y` 한 줄 요약을 기본으로 합니다.

## 만든 배경

기존 ComfyUI 코파일럿을 실제 파이프라인에서 쓰다가 한계(인코딩 버그, 기능 비대로 인한
토큰 과다 등)를 겪었고, 그 내부 구조(**MCP 도구 연동 + 실시간 캔버스 브릿지**)를 제대로
이해하려고 **밑바닥부터 재구현**한 프로젝트입니다.

"기존 도구를 이기는 신제품"이 목표가 아니라 — **동작 원리를 이해하고, 내 워크플로우에 맞게
확장할 수 있는 내 도구를 갖는 것**이 목적입니다.
